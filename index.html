How the model gets built

Six stages, run in order, from a raw CSV export off NOAA's servers to a forecast that reaches into 2027.

  1. 01

    Load & clean

    Pull daily records from NOAA, keep the columns that matter, average max and min into a single air temperature, and drop incomplete rows.

  2. 02

    Engineer features

    Derive yesterday's temperature, 2- and 7-day lags, 7- and 30-day rolling averages, and a season flag — so the model sees trends, not just a single day.

  3. 03

    Split train / test

    Everything before January 1, 2024 trains the model. Everything after is held out — the model never sees it until it's asked to predict it.

  4. 04

    Train the forest

    100 decision trees, each built on a random subset of the data, average their votes into one prediction — steadier than any single tree.

  5. 05

    Measure accuracy

    Score predictions against the held-out set with MAE and RMSE — the second one punishes big misses harder than small ones.

  6. 06

    Forecast forward

    Roll the model's own outputs forward day by day through the end of 2027, blended with historical seasonal averages so it still breathes with the seasons.

What broke, and the fix

Three problems came up while building this. None of them were the model itself.

API connectivity

Lost connection to the data source mid-integration.

Fix Reconnected on a new server and hosting port.

Monthly data display

The front end couldn't render the full monthly archive — gaps in the dataset broke the display.

Fix Looped through the dataset to backfill missing months before rendering.

Forecast line ran flat

The 2027 forecast stopped following seasonal swings — it converged toward a flat average instead of curving through summer and winter.

Fix Blended the model's raw output 70/30 with the historical seasonal average for that day of year.

Where this goes next

More history, more factors

Train on a longer record — closer to five decades — with more variables, to see current warming trends against a real baseline instead of twelve years.

Go beyond one station

Bring in a global dataset that updates on a schedule, so the model — and the forecasts it produces — cover more than one airport.
